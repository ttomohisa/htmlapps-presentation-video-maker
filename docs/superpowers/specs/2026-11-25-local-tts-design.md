# Presentation Video Maker v2.0.0 日英ローカル音声合成

## 目的

発表者が日本語・英語の台本をブラウザ内で音声に変換し、画面共有やマイクの許可を求められずにナレーション付きMP4を作れるようにする。スライドごとの音声設定に「ローカルTTSモデル」を追加する。既存のブラウザ読み上げ、録音、音声ファイルも同じ資料で使える。

## 配布方式

| 検討した方式 | 利用者の操作と配布側の負担 |
| --- | --- |
| Hugging Faceの既存ファイルを案内（採用） | モデル本体と使いたい声を保存し、アプリでまとめて選ぶ。配布元と利用条件を直接確認できる。 |
| Cloudflareで日英セットを配布 | 1回のダウンロードで済む。運営側が再梱包、ライセンス表示、更新、ホスティングを管理する。 |

Kokoro-82M v1.0 の量子化ONNX（約92 MB）を日英で共用する。最初の検証対象は日本語の jf_alpha と米国英語の af_heart（各約522 kB）。配布リンクは検証したリビジョンに固定し、アプリには容量、話者名、出典、利用条件を表示する。モデル、話者、読み変換用の辞書、推論ライブラリの利用条件と必要な表示を個別に確認し、同梱物について第三者ライセンス表記を更新する。[モデルカード](https://huggingface.co/hexgrad/Kokoro-82M)・[話者情報](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md)・[ONNX配布元](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX)

## 台本から動画まで

1. 音声方式で「ローカルTTSモデル」を選び、必要なファイルの案内を開く。既に保存したファイルは直接選択できる。モデルと声は別々のタイミングでも追加でき、不足時は必要なファイル名を表示する。
2. 資料の既定言語を日本語か英語に設定する。スライドでは「資料の設定に従う」、日本語、英語から選べる。画面の表示言語とは独立させる。対象言語に対応する声で、入力した台本をそのまま読む。翻訳は利用者が用意する。
3. 選択スライドを生成して試聴し、必要に応じて台本や速度を修正する。一括生成は動画に含めるローカルTTSのスライドのうち未生成・要更新・失敗のものを順番に処理する。空の台本は既存の読み上げと同様に読み飛ばす。進捗、対象スライド、中止操作を表示する。
4. 生成結果をスライドの音声素材として登録し、その実測時間をMP4と字幕に反映する。既存の前後余白、BGM、字幕、トランジションを適用する。

## オフライン処理と保存

利用者が明示的に開く配布リンクだけが外部サイトへの移動になる。モデルと声は端末のファイル選択から読み込む。日本語の漢字・かな、米国英語の綴りをモデルの入力に変換する処理、辞書、推論ランタイムは単一HTMLのオフラインビルドで利用できるようにする。初回利用時の裏側での取得にも依存しない。既存の通信制限を維持し、重い処理は画面操作を妨げず、スライドを順次処理してメモリを解放する。

生成音声、資料の既定言語、スライドの言語指定、話者、速度、モデルの識別情報を .pvm に保存する。モデル・声のファイルはプロジェクトに複製しない。再開後は生成済み音声をそのまま試聴・出力でき、再生成時にファイルを選択する。v1.x形式を読み込む経路は保持する。新形式の読み込みが必要な場合は、旧版への保存互換性を仮定しない。

台本・実効言語・声・速度の変更で影響を受ける音声を要更新にする。新しい音声の生成と検査が完了してからスライドの素材を置換する。中止・失敗時は完了済みの素材を保ち、該当スライドから再試行できる。生成中の編集や資料切替によって古い結果が別のスライドに適用されないようにする。

## v2.0.0の確認項目

- デスクトップ版Chromiumで実際の配布ファイルを選び、漢字・数字・句読点を含む日本語と、数字・略語を含む米国英語をそれぞれ試聴する。長い台本は文単位などで分割して末尾まで読む。
- 日英混在の資料でスライド単体・一括の両方を生成する。実際にMP4を書き出し、スライド順、音声、字幕のタイミングを確認する。
- 生成済みの .pvm を別セッションで開き、モデルを選び直す前に試聴・MP4出力できること、1枚の編集後にそのスライドだけを再生成できることを確認する。v1.xのプロジェクトでも従来の音声を確認する。
- モデル不足、話者の取り違え、破損ファイル、一括処理の中止を試す。ネットワークを遮断した単一HTMLでも日英の生成を試し、ビルドと既存の検証を実行する。
- 新方式の動作確認対象を利用案内に明記する。スマートフォンでは既存の録音・音声ファイルの導線を維持し、新方式の対応表示は実機確認に合わせる。

推論ライブラリ、読み変換実装、音声の内部形式、処理の分割方法は実装時の選定事項とする。ライセンスと単一HTMLでのオフライン実行を確認し、実際の日英音声を通してから採用する。
