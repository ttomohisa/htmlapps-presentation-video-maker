# 日英ローカル音声合成の実装計画

[設計書](../specs/2026-11-25-local-tts-design.md)に従い、独立した音声推論、読み変換、スライド編集の各部分を検証してから結合する。

- [x] ブラウザのワーカーで ONNX Runtime を初期化し、選択した Kokoro モデルと話者で音声を生成する。モデル不足、声の破損、長文による入力上限を検証する。
- [x] 日本語と英語の文字列をオフラインで Kokoro の音素列に変換し、辞書とライブラリの配布条件を記録する。
- [x] 音声方式、ファイル選択、シーン言語、単体・一括生成、中止、音声の状態表示を既存テンプレートに組み込む。資料切替と生成が重なった場合の結果の扱いを確認する。
- [x] 生成音声と設定をプロジェクトに保存・復元し、v1.x のプロジェクトを読み込む。実測時間で字幕と動画を生成する。
- [x] 依存資材の固定、単一HTMLビルド、バージョンと利用案内の更新を行い、実際のモデルで日英資料の生成・再開・MP4出力をブラウザで検証する。
